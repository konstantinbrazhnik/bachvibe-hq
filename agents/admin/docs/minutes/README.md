# Minutes and resolutions — drafts

Admin drafts here; the founder signs and files to the records location, then
`RECORDS.md` gets the line. A draft is `draft-<YYYY>-annual-meeting.md` or
`draft-<YYYY-MM-DD>-resolution-<slug>.md`. Once filed, the draft is deleted
here and the record is indexed — the repository is not the minute book.

A draft annual-meeting packet contains: the notice (or the waiver), the
agenda, the minutes with attendees and each item's resolution, and any
written consent in lieu of a meeting, in the form the governing document
prescribes. Read the operating agreement or bylaws (location in
`REGISTRY.md`) before drafting; the form is theirs, not a template's.
