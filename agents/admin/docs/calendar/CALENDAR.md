# Compliance calendar

One row per obligation. `Due` is the real deadline; `Lead` is how far ahead
the reminder card is created; `Source` is the statute, contract or vendor
page that says so (a URL or a citation, re-checked monthly). Status is one
of `unknown`, `scheduled`, `card #`, `filed <date>`, `n/a (reason)`.

Everything below is a **template**: rows are placeholders until the entity
decision (`REGISTRY.md` "Open") fixes the state and kind. Do not invent a
date; `unknown` is the honest value.
